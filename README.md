# Netflix Desktop App

A Netflix-like desktop application built with PyQt5, VLC, and MySQL.

## Features
- User login & registration system
- Video player with VLC support
- Watch history & resume from where you left off
- Favorites list & rating system
- Admin panel with reporting & statistics

## Requirements
- Python 3.x
- PyQt5
- python-vlc
- mysql-connector-python

## Installation
pip install PyQt5 python-vlc mysql-connector-python

## Usage
1. Set up a MySQL database named `netflix_db`
2. Update the connection settings in `get_connection()`
3. Run: python main.py
